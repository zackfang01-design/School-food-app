# 學校115廚餘總重紀錄 APP

這是一個可直接在 iPhone Safari 開啟的手機版網頁 App。

功能：
- 星期一～星期五分開紀錄
- 每筆輸入組別與重量
- 依照片下方的扣重表自動計算：1組=2.6kg、2組=5.2kg……60組=156.0kg
- 自動計算每日重量加總、扣重加總、廚餘淨重
- 自動計算週一～週五總計
- 資料儲存在手機瀏覽器 localStorage
- 可直接用 GitHub Pages 免費發布

使用方式：
1. 將 index.html 上傳到 GitHub 儲存庫。
2. GitHub → Settings → Pages → Deploy from branch → main / root。
3. 等待部署後，用 iPhone Safari 開啟 GitHub Pages 網址。
4. Safari 分享 → 加入主畫面，即可像 App 一樣使用。

注意：目前資料只保存在該裝置的瀏覽器；若清除 Safari 網站資料，紀錄也會消失。
